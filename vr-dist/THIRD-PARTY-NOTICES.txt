The program
-----------
openxcom.exe is OpenXcom Extended (OXCE) 8.7.1 with the VR tabletop
prototype added. OpenXcom and OpenXcom Extended are free software under the
GNU General Public License, version 3 or later (see LICENSE.txt).

Complete corresponding source code for this build:
  https://github.com/MarkAnthonyM/OpenXcomVR  (branch vr-prototype,
  tag proto-<version>; the exact commit is in BUILD-INFO.txt)

README-VR.md ("Building") in the source describes how to build the program,
including against your own build of any of the libraries below (as the LGPL
allows for SDL).

This package does not contain any data from the original X-COM: UFO Defense.
You need your own copy of the game.
